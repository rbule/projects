## All my projects
### EBuy Spring Boot API
An API made with Spring Boot in Java that follows a microservices design for scalability and easier maintaining.
The project is made to be a Docker container and can be run using docker compose --build --detach

### Trello-like Frontend for the EBuy API
Built using React.js in the TypeScript programming language

### Feed-forward neural network
Neural network made completely from scratch. The only external libraries used are the datasets and numpy. Made to understand backpropagation and
how neural networks work

### Original Space Invaders clone
Clone of the game built in SFML using C++
